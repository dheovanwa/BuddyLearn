Buddy Learn adalah Aplikasi Edukasi android yang menggunakan AI untuk membantu pengguna tunanetra mengakses materi pendidikan dengan cara membacakan suatu bagian layar saat ditahan.  

## Fitur Utama
- AI membacakan teks di layar secara real-time.
- Navigasi aplikasi dibantu suara agar mudah digunakan.
- Modul pembelajaran audio yang bisa diakses kapan saja.
- Pengaturan suara bisa disesuaikan: kecepatan, volume, dan jenis suara.

## Cara Install
1. Clone project ini.
2. Buka di Android Studio.
3. Build & jalankan di emulator atau device Android.
